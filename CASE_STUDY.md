# Case Study: AI Study Planner Dashboard

## Problem

The AI Study Planner needed a central dashboard where a student could
view subjects, manage today's study tasks, see upcoming deadlines,
and follow a daily study plan.

## What I Did

I created a new Dashboard route at `/dashboard` using Next.js and
Tailwind CSS.

The dashboard includes:

- Subject progress with visual progress bars
- Today's Tasks
- Upcoming Deadlines
- Daily Study Plan

I then added interactive task management. Students can:

- Add a new task with a title, subject, and time
- Mark tasks as completed
- Delete tasks
- See the number of completed tasks update automatically

I also added the Dashboard link to the main navigation.

The feature was tested locally, and the project was checked with the
production build and automated test suite before committing the work
to GitHub.

## What Came of It

The AI Study Planner now has a functional student dashboard instead
of a static placeholder page.

The Dashboard provides a single place to organize study activities
and track task completion.

The feature is available at:

https://ai-study-planner-inky-seven.vercel.app/dashboard
