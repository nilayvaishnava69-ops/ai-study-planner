# AI Study Planner

AI Study Planner is a student productivity application designed to help organize academic tasks, manage study preferences, and create a personalized study planning workspace.

## Installation

Make sure Node.js, npm, and Git are installed.

Clone the repository:

```bash
git clone <repository-url>

Move into the project directory:

cd ai-study-planner

Install the project dependencies:

npm install
Running the Project

Start the Next.js development server:

npm run dev

Then open:

http://localhost:3000

Available Routes

The application currently includes the following pages:

Home
Academic Profile
Study Preferences

Notifications

Health Check

/
 /academic-profile

Production Build

Create an optimized production build:

npm run build

Start the production server:

npm start
Testing

Run the automated test suite:

npm test

Development Conventions
Keep the code simple and readable.
Use meaningful variable and function names.
Keep functions small and focused.
Use React and Next.js conventions consistently.
Use Tailwind CSS for styling.
Forms should include appropriate validation and visible error messages.
Important application behavior should have automated tests.
Keep pages keyboard accessible and use appropriate accessibility attributes.
Update documentation when project behavior changes.
Verify the application locally before committing changes.
Use clear and descriptive Git commit messages.
Deployment

Every push to the main branch can trigger a new Vercel deployment.
